# Record a Browser Tutorial

In the desktop Browser panel, Shift-click the screenshot button to start recording.
Click it again to stop and save. You can also ask an agent to record its browser
actions; its recording tools save the resulting video in the connected environment.
Choose the browser profile that holds the logins needed for your tutorial.

Set **Recording Pointer** in **Settings → Browser** before starting a recording.
Choose an arrow, Precision Ring or an angular Delta, Kite or Chevron, or import a PNG,
WebP or SVG image. Adjust its size and hotspot. The hotspot is
the point on the image that touches the click target; X and Y are percentages of
the image's width and height. The preview lets you test the pointer and click halo.
Transparent images work best. Imported images are stored with your settings.

**Show Pointer** controls pointer visibility. **Click Halo** highlights clicks and
held mouse buttons; set its colour, radius and duration beside the pointer controls.
The corner sample plays the halo animation when you click the preview or change its colour.
Fill and outline colours apply to the presets. **Reset Pointer** restores
the default image and appearance while preserving your halo visibility choice.

New desktop and agent recordings use the saved configuration. An ongoing recording
keeps the configuration it started with. Browser recording frame rate and key-press
display are in the same settings section.
